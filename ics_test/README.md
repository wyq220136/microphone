# ICS 双麦克风 BLE 固件

本目录实现 ICS-43434 双麦克风采集、轻量 DSP 融合和 BLE PCM16 音频发送。Arduino 草图作为项目入口；模块间通过配置命名空间、处理器对象和协议结构体协作，避免应用状态散落为全局变量。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `ics_test.ino` | Arduino `setup()` / `loop()` 入口 |
| `app_controller.h/.cpp` | 初始化与主循环；管理录音生命周期、采集调度和诊断输出 |
| `cfg.h` | `IcsTestConfig` 命名空间内的引脚、采样、BLE、包队列参数 |
| `I2SSampler.h/.cpp` | 安装/卸载两个 I2S RX 端口并读取原始采样 |
| `audio_pipeline.h/.cpp` | 左右声道滤波与等权平均融合，持有滤波器状态 |
| `algorithm.h/.cpp` | 离线 WPE/MVDR 和固定容量流式 DSP 算法，API 位于 `IcsDSP` 命名空间 |
| `packet_protocol.h/.cpp` | 14 字节小端包头、PCM16 音频负载与控制包序列化 |
| `ble_transport.h/.cpp` | NimBLE 服务、连接回调、发送任务、队列与通知统计 |
| `button.h/.cpp` | 带消抖的按键状态对象 |
| `ble_ics_receiver.py` | BLE 接收端脚本；解析包并保存 WAV |

## 数据流

左右 ICS-43434 麦克风分别由 I2S0/I2S1 以 8 kHz、32 位槽位采样。`AudioPipeline` 对每个通道做增益、直流阻断和抗混叠滤波，按 2:1 降采样到 4 kHz 后将左右通道等权融合为单声道。协议层将每 115 个 PCM16 样本封装为 244 字节数据包，再进入 BLE 有界队列，由独立任务逐包通知客户端。

按键按下时发送 START 控制包并重置滤波状态；再次按下时补发两个静音块以排出滤波尾部，再发送 END。连接断开后应用停止录音，重连时重新初始化这一轮音频状态。

## 包格式

包头共 14 字节：`A5 5A` 魔数、类型、声道数、采样率、帧数、序号和负载字节数；多字节字段为小端序。类型值为 DATA=1、START=2、END=3。音频负载是有符号小端 PCM16 单声道数据。ATT MTU 请求为 247，因此单个通知最多承载 244 字节。

## 调参入口

硬件引脚、采样率、滤波位移、BLE UUID、MTU、包队列深度和连接参数集中在 `cfg.h`。数据包格式的字段布局由 `packet_protocol.cpp` 负责；不要只修改固件端字段而不同步修改接收端解析器。左右麦克风使用独立时钟，实际同步性需要在目标硬件上验证。

## 验证

使用 ESP32-S3 Arduino 环境打开 `ics_test.ino` 编译并烧录。串口输出包含连接、初始化、发送、丢包、DSP 超时和通知状态统计。目录中的接收脚本可与设备配合测试 BLE 收音和 WAV 落盘。

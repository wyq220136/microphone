处理说明

使用 Web Audio 的因果 biquad。以 16 kHz 解码、处理并导出单声道 PCM24。每次生成从零状态开始，不改变录音长度。

PEQ 用于调整低中频能量；它不移动人声谐波，也不恢复削波、丢包补零或声学抵消造成的损失。请同时听闷厚感、自然度和声音是否变薄。

固定 WAV 与频谱可用 Python 脚本按下载的 JSON 重新生成，详见 使用说明。公式依据 Audio EQ Cookbook。
